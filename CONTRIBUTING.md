# 🛠️ Contributing to OSCC Connect Support ❤️

Thank you for choosing to contribute to the onboarding and support repository of **Odisha Students Code Community (OSCC)**! 👋

---

## 🌟 How Can I Contribute?

### 1️⃣ Report Issues or Share Ideas 💡
If you have questions about the organization, find bugs in the auto-invite workflow, or want to suggest improvements:
- Open a **[New Issue](https://github.com/Odisha-Students-Code-Community/Connect/issues/new)**.
- Use a clear, descriptive title.

### 2️⃣ Submit Pull Requests (PRs) 🚀
1. **Fork** the repository and create your feature branch from `main`.
2. Commit your changes with clear messages.
3. Open a **Pull Request** and describe what your changes do.

Thank you for making Odisha Students Code Community awesome! ❤️
