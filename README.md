## ⚡ How It Works

OSCC Connect uses **GitHub IssueOps Automation** to onboard students automatically:

1. **Submit Invitation Issue**: Open an issue using the [Community Invitation Template](https://github.com/Odisha-Students-Code-Community/Connect/issues/new?template=invitation.yml).
2. **Automated Processing**: Our GitHub Actions onboarding workflow triggers immediately, adds your GitHub account to the `Odisha-Students-Code-Community` organization, and comments with your invite link.
3. **Accept Invitation**: Check your notifications or visit [github.com/orgs/Odisha-Students-Code-Community/invitation](https://github.com/orgs/Odisha-Students-Code-Community/invitation) to accept.
4. **Make Membership Public**: Navigate to the [OSCC People Directory](https://github.com/orgs/Odisha-Students-Code-Community/people), search your username, and change the dropdown from **Private** to **Public** to display the OSCC badge on your GitHub profile.
